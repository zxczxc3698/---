# 제갈량 상소문

매일 오전 7시(KST), 승상 제갈량이 표문 형식으로 올리는 조언.

- **其一 · 도구를 부리는 법** — Claude Code를 잘 쓰는 법 (2,000자 이상)
- **其二 · 뜻을 세우는 법** — 비즈니스와 삶의 방향 (3,000자 이상)

상소문: https://claude.ai/code/artifact/8ef57367-29d9-4e77-9797-bd1a6053885b

## 구성

| 조각 | 하는 일 |
| --- | --- |
| `sangsomun.html` | 상소문 페이지의 원본. Artifact로 배포되어 있다. |
| `sangso-2026-09-06.json` | 첫 표문. db 문서 서식의 본보기. |
| `routine-prompt.md` | 매일 오전 7시에 도는 루틴이 받는 지시문. |

### 페이지

한지·먹·주사 인장의 표문 형식. 두 가지 런타임 기능을 쓴다.

- `db` — 표문이 `sangso/<YYYY-MM-DD>` 문서로 쌓인다. 페이지는 가장 최근 것을 띄우고,
  「역대 상소문」에서 지난 것을 다시 읽을 수 있다. 쓰기는 `admin` 이상으로 막아 두었다.
- `sample` — 「하문(下問)」 창에서 승상께 되물으면 같은 문체로 답한다.

db를 쓸 수 없는 자리(저장한 사본, 미리보기)에서는 HTML에 박아 둔 첫 표문이 그대로 보인다.

### 루틴

`0 22 * * *` (UTC) = 매일 오전 7시 KST. 발동할 때마다 새 세션이 열려서

1. 아티팩트 db에서 지난 닷새 치 표문을 읽어 서식을 맞추고 같은 이야기를 피한다
2. 최근 세션 목록을 훑어 요즈음 무슨 일을 하고 있는지 파악한다
3. 그날의 표문을 지어 `sangso/<오늘 날짜>`에 넣는다
4. 휴대폰으로 알림을 보낸다

페이지는 새로 배포하지 않는다 — db에 넣기만 하면 열려 있는 페이지가 알아서 바뀐다.

## 고치는 법

- **시각을 바꾸려면** — 루틴의 cron을 고친다. UTC 기준이므로 원하는 KST 시각에서 9시간을 뺀다.
- **문체나 분량을 바꾸려면** — `routine-prompt.md`를 고쳐 루틴 프롬프트에 반영한다.
- **디자인을 바꾸려면** — `sangsomun.html`을 고쳐 같은 URL로 다시 배포한다.
