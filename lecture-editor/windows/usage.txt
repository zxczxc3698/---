강의 영상 자동 편집 — 윈도우 사용법
====================================

처음 한 번만
-------------
1. "setup.bat" 을 두 번 누른다.
2. 설치가 끝나면 창을 닫고 다시 한 번 눌러 확인한다.
   (파이썬과 ffmpeg 를 깔 때마다 창을 닫았다 다시 열어야 한다)
3. "준비 끝났습니다" 가 나오면 된 것이다.

인터넷이 막혀 있거나 winget 이 없으면 아래 둘을 직접 받는다.
  파이썬  https://www.python.org/downloads/
          설치할 때 "Add Python to PATH" 를 반드시 체크한다
  ffmpeg  https://www.gyan.dev/ffmpeg/builds/
          받은 폴더의 bin 을 시스템 PATH 에 넣는다


편집하기
---------
방법 1  영상이 든 폴더를 "edit.bat" 위에 끌어다 놓는다.
방법 2  "edit.bat" 을 두 번 누르고, 폴더 경로를 넣는다.

몇 가지를 물어본다. 그냥 엔터를 치면 기본값으로 간다.

  · 칠판 글씨가 뒤집혀 있는가   앞 카메라로 찍었으면 "예"
  · 어떻게 잘라낼까             앉아서 말하면 1번, 움직이며 찍었으면 2번
  · 화질                        유튜브에 올릴 것이면 "높게"

결과는 영상 폴더 안 "편집결과" 폴더에 쌓인다.
강의마다 폴더가 하나씩 생기고 그 안에

  final.mp4              완성본
  subs.srt               자막 파일. 유튜브에 따로 올려도 된다
  youtube_chapters.txt   챕터를 넣었으면 설명란에 붙일 목록


오래 걸린다
------------
영상 길이의 1.5배쯤 잡는다. 10분짜리면 15분 안팎.
40편이면 하룻밤이다. 자기 전에 걸어 두면 된다.

창을 닫아도 괜찮다. 다시 실행하면 끝난 것은 건너뛰고 이어서 한다.


자막 고치기
------------
받아쓰기는 전문 용어를 틀린다. 고치는 자리가 있다.

1. lecture-editor 폴더의 terms.txt 를 연다.
2. 강의에서 쓰는 말을 한 줄에 하나씩 적는다. (707특임단, 천리행군, IBS ...)
3. 이 목록이 받아쓰기 전에 모델에게 건네져서 오인식이 줄어든다.

이미 만들어진 자막을 손보려면 편집결과 폴더의 subs.srt 를 메모장으로 고친 뒤,
그 강의만 다시 렌더하면 된다. 받아쓰기를 다시 하지 않으니 훨씬 빠르다.


잘 안 될 때
------------
"python 을 찾을 수 없습니다"
   설치할 때 "Add Python to PATH" 를 빠뜨린 것이다. 파이썬을 지우고 다시 깐다.

받아쓰기에서 멈추거나 튕긴다
   오래된 CPU 는 받아쓰기 엔진을 못 돌린다. setup.bat 의 확인에서 걸러진다.
   그런 경우 자막 없이 컷 편집만 쓸 수 있다.

자막 글씨가 깨져 보인다
   윈도우 기본 한글 글꼴(맑은 고딕)을 쓴다. 지웠다면 다시 깔면 된다.

너무 많이 잘려 나간다 / 너무 안 잘린다
   lecture-editor/README.md 의 --minlen, --db 설명을 본다.
